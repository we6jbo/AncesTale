# VVWK (AncesTale 0.4.0)
Build Qt under the existing AncesTale/build directory. Click VVWK > Init, approve the SSH deployment and complete any Tailscale authentication manually. No SSH key or host verification settings are changed. The page is deployed at /home/jeremiahai/www/nov-game/VVWK/index.html. Existing different files are refused. The backend module is installed outside the document root at ~/.local/share/ancestale-vvwk/backend.py.

The browser diagnostics work independently of the API. Enrollment requires explicit consent; the random HttpOnly cookie maps to the chosen game label, observed peer IP and capability report in the private enrollments.json file. A user can delete their enrollment; expired entries are purged on the next API request (not by a background process). HTTP on the LAN is not encrypted. No hardware serial, MAC, device ID, canvas fingerprint or GPU renderer string is collected. IP is not identity; browser feature support does not guarantee audio output. The test chime requires a click.
