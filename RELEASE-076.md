# AncesTale 0.7.6
Install over v0.7.5. Native desktop handoff includes new narration and alpha2 instructions. Shared JS and fallback HTML provide local voice selection, independent voice mute/replay, scalable text and music ducking; rails waits while speaking. Alpha2 preview provides four prepared scenes and proposed cues, not a full dynamic Vibe replacement. Use local preview with ?preview=1, not live mode outside scheduled window. No source database or signed assets modified. Browser voice availability, live Pi authentication/presence/progress, audio and end-to-end Qt build require device tests. The publication helper runs only under owner control, with explicit stage/publish prompts. No automatic Git actions, email or deployment by installer. Earlier v0.7.4 and v0.7.5 updates must be installed first.
