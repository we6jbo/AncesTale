Native Continued Research tab. Requires existing private JSON at /home/we6jbo/Projects/AncesTaleextended/missing_family_records.json. Install with python3 install-review.py --apply, then rebuild from project root. Source patch only, no Pi, email, Git, signed-file or JSON modifications during installation. Qt development libraries unavailable in packaging environment: compile and runtime tests on T14 required. Use one writer at a time: the earlier standalone Python UI does not share the Qt lock. Close it while changing records in the native UI or having Vibe update them. Checkmarks are pending indicators, not editable toggles; Resolve with evidence and Reopen change status explicitly. Unknown fields do not prevent evidence-backed resolution. Missing-field column covers six vital/parent fields; evidence pane shows all fields including relationships. Read-only review and prompt copying work without rewriting records. Do not publish research queue.
